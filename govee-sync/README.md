# Govee TV Sync

Фоновое приложение для **Android TV / Google TV**, которое автоматически включает и выключает подсветку **Govee TV Backlight 3 Lite (H6097)** (и другие устройства Govee с поддержкой OpenAPI) вместе с телевизором.

## Как работает

Модель **H6097** не поддерживает локальный UDP LAN API, но официально работает через облачный **Govee OpenAPI v1** (`https://openapi.api.govee.com`).

Приложение держит лёгкую фоновую службу (`MonitorService`) и подписывается на системные события телевизора:

| Событие телевизора | Действие с подсветкой |
|---|---|
| Включение экрана / выход из сна (`ACTION_SCREEN_ON`) | Включить (`powerSwitch = 1`, с автоповторами, пока поднимается Wi-Fi) |
| Выключение экрана / переход в сон (`ACTION_SCREEN_OFF`) | Выключить (`powerSwitch = 0`, с коротким `PARTIAL_WAKE_LOCK`, чтобы запрос успел уйти до глубокого сна) |
| Загрузка ТВ (`BOOT_COMPLETED`) | Автозапуск службы + включение подсветки (опционально) |
| Полное выключение ТВ (`ACTION_SHUTDOWN`) | Выключить (`powerSwitch = 0`) |
| Заставка / Ambient Mode (`DREAMING_STARTED` / `STOPPED`) | Опционально: выключить при заставке и включить при выходе |

## Установка и настройка

### 1. Получите API-ключ Govee (один раз)
1. Откройте приложение **Govee Home** на телефоне.
2. Перейдите в **Профиль** (иконка человека) → **Настройки** (шестерёнка) → **Apply for API Key**.
3. Заполните форму (в причине можно указать *Personal home automation*) — ключ придёт на почту через пару минут.

### 2. Установите APK на телевизор
Скачайте [`../govee-sync.apk`](../govee-sync.apk) и установите любым способом:

```bash
adb install -r govee-sync.apk
```

*(или через Send Files to TV / флешку / Downloader).*

### 3. Удобная настройка с телефона или ПК (без набора ключа пультом)
1. Откройте **Govee TV Sync** на телевизоре.
2. В блоке **«Быстрая настройка с телефона или ПК»** появится адрес вида `http://192.168.1.42:8765`.
3. Откройте этот адрес в браузере телефона (в той же Wi-Fi сети):
   - вставьте ваш `Govee API Key`;
   - нажмите **«Найти устройства Govee»** — ваша **H6097** подтянется автоматически первой в списке;
   - нажмите **«Сохранить»** и проверьте кнопками **«Тест: Вкл»** / **«Тест: Выкл»**.

> Веб-сервер работает только пока на телевизоре открыт экран настроек `Govee TV Sync` — при выходе он сразу останавливается.

### Альтернатива: настройка одной командой через `adb`

```bash
adb shell am start -n io.github.toxageek.goveesync/.SettingsActivity --es api_key "<ВАШ_GOVEE_API_KEY>"
```

Приложение само сохранит ключ, загрузит список устройств и автоматически выберет `H6097`.

## Энергосбережение на Android TV
Если прошивка ТВ агрессивно убивает фоновые службы, рекомендуется исключить приложение из оптимизации батареи:

```bash
adb shell dumpsys deviceidle whitelist +io.github.toxageek.goveesync
```

## Сборка

**Android Studio:** откройте папку `govee-sync/` и соберите `app`.

**Без Gradle** (чистый Android SDK + JDK):

```bash
bash govee-sync/build.sh   # результат: ./govee-sync.apk
```

Код — чистая Java 8 без сторонних библиотек (только Android SDK), APK весит ~50 КБ.
Ключ подписи `signing/govee-sync.keystore` лежит в репозитории намеренно (как в `lampa-voice`), чтобы новые сборки ставились поверх предыдущих без переустановки.
