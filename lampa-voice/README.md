# Lampa Voice

Голосовой поиск фильмов в **Lampa** прямо из системной кнопки микрофона Android TV / Google TV.

Зажимаете микрофон на пульте → говорите «Интерстеллар» → выбираете **Lampa**
(или YouTube / Google, как раньше) → Lampa открывается сразу с результатами поиска.

Состоит из двух частей:

| Часть | Файл | Что делает |
|---|---|---|
| Android-приложение | [`../lampa-voice.apk`](../lampa-voice.apk) | Перехватывает кнопку ассистента, распознаёт речь, передаёт фразу |
| Плагин Lampa | [`../voice-search.js`](../voice-search.js) | Забирает фразу и открывает поиск Lampa |

## Почему два компонента

Плагин Lampa — это JavaScript внутри WebView: он живёт только пока Lampa открыта
и не может зарегистрироваться в системе как обработчик голосовой кнопки — это делается
только в манифесте APK. А официальный APK Lampa закрытый и не умеет принимать текст
поиска через intent. Поэтому:

```
Пульт (микрофон) ──► Lampa Voice ──► системный распознаватель Google
                         │
                         ├─ «Lampa»   ──► кладёт фразу в HTTP-сервер 127.0.0.1:39876 (живёт ~90 с)
                         │               └─► выводит Lampa на экран ──► плагин забирает фразу ──► Lampa.Search
                         ├─ «YouTube» ──► поиск в YouTube
                         └─ «Google»  ──► та же выдача Google, что и раньше (фраза уже распознана)
```

## Установка

### 1. Приложение

Скачайте [`lampa-voice.apk`](../lampa-voice.apk) и установите на ТВ любым способом:
`adb install lampa-voice.apk`, «Send Files to TV», Downloader и т.п.

### 2. Плагин

Lampa → Настройки → Расширения → Добавить плагин:

```
https://cdn.jsdelivr.net/gh/toxageek/lampa-plugins@master/voice-search.js
```

> Ссылка через jsDelivr, а не raw.githubusercontent.com: raw отдаёт файл как `text/plain`,
> и WebView его не исполнит. jsDelivr кэширует ветку до 12 часов.

### 3. Назначить Lampa Voice ассистентом (один раз, через adb)

На Google TV нет пункта меню «ассистент по умолчанию», поэтому — с компьютера.

1. Включите режим разработчика: Настройки → Система → Об устройстве →
   7 раз нажмите «Сборка ОС Android TV».
2. Настройки → Система → Для разработчиков → «Отладка по USB» / «Отладка по Wi-Fi».
3. На компьютере:

```bash
adb connect <IP-телевизора>     # для Wi-Fi-отладки на Google TV 12+ сначала: adb pair <IP>:<порт>

# Запомните текущего ассистента — чтобы потом вернуть:
adb shell cmd role get-role-holders android.app.role.ASSISTANT

# Назначить Lampa Voice:
adb shell cmd role add-role-holder android.app.role.ASSISTANT io.github.toxageek.lampavoice
```

Вернуть как было (подставьте пакет, который показала команда `get-role-holders`,
на Google TV обычно это `com.google.android.katniss`):

```bash
adb shell cmd role add-role-holder android.app.role.ASSISTANT com.google.android.katniss
```

Откройте Lampa Voice из списка приложений — в разделе «Состояние» будет видно, назначен ли он.

### Если кнопка всё равно открывает Google

На некоторых пультах и прошивках кнопку Assistant обрабатывает сам Google, минуя
системную роль ассистента. Тогда переназначьте кнопку приложением **Button Mapper**:
долгое нажатие микрофона → «Ярлык / Активность» → **Lampa Voice → Голосовой поиск**.

## Настройки приложения

- **Проверить: сказать фразу** — тот же сценарий, что и по кнопке.
- **Приложение Lampa** — автоопределение по названию или выбор вручную (для форков).
- **После распознавания** — спрашивать, где искать, или сразу открывать Lampa.
- **Язык распознавания** — системный, русский, украинский, английский.

В Lampa: Настройки → **Голосовой поиск** — включение и кнопка «Проверить связь».

## Безопасность

- Сервер слушает только `127.0.0.1` — с других устройств сети он недоступен.
- Работает ~90 секунд после голосового запроса, а не постоянно; фраза одноразовая и живёт 60 секунд.
- Проверяется заголовок `Host` (защита от DNS rebinding из браузера на ТВ).
- Разрешения: только `INTERNET` (нужно, чтобы открыть локальный сокет). Микрофон приложению
  не нужен — речь распознаёт системный экран Google.
- Ключ подписи `signing/lampa-voice.keystore` лежит в репозитории намеренно: так APK,
  собранный любым способом (скриптом или Android Studio), ставится поверх предыдущего.
  Хотите свой ключ — передайте `KEYSTORE`/`KEYSTORE_PASS`/`KEY_ALIAS` в `build.sh`
  (обновление поверх старой версии тогда потребует переустановки).

## Сборка

**Android Studio:** откройте папку `lampa-voice/` и соберите `app`.

**Без Gradle** (нужны aapt, d8 или dx, apksigner и android.jar):

```bash
ANDROID_HOME=~/Android/Sdk bash lampa-voice/build.sh   # результат: ./lampa-voice.apk
```

Код — Java 8 без библиотек (только Android SDK): APK весит ~50 КБ, собирается
даже без Android Gradle Plugin, а лямбд нет, чтобы подходил и старый `dx`.

## Ограничения

- Проверено: сборка, подпись (v1+v2+v3), выравнивание APK, обмен «сервер ↔ плагин» в Chromium.
  На живом Google TV сценарий с кнопкой пульта зависит от прошивки — см. раздел про Button Mapper.
- Если WebView Lampa блокирует запросы страницы к `http://127.0.0.1`, плагин автоматически
  повторяет запрос через нативный HTTP-клиент Lampa (`AndroidJS`).
